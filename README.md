### Macro keyboard based on arduino pro micro (stl and code)

**Component**:
* Arduino pro micro 
* Keyboard switches
* Jumper wires
* PLA (any color)

_**Notes**:
Any other material can be used for the print, the usb slot may be to thick for some cable so consider sanding the slot (be careful since pla tend to deform with heat) or using a cable with a slimmer port. Any board using ATmega32U4 chip can be used since they can act as usb HID_
